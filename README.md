# The Smash Grill Kitchen

I want you to create a website exactly similar to the reference in IMG-20261026-WA0010.jpg but for The Smash Grill using the menu in IMG-20261026-WA0008.jpg and also the style guide on the poster menu, using the attached photos and logo. It's an e-commerce restaurant store with a cart page where people can add items and see recommendations. It is a pickup order setup (The Smash Grill Kitchen, 066 334 3526). Once a customer fills out all their details, direct the order to WhatsApp with the formatted order summary, and provide a digital receipt after ordering.
